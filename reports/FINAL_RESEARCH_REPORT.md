# Итоговый отчёт: исследование стратегий MOEX на годе данных T-Invest

Дата: 2026-09-25. План: `research/RESEARCH_PLAN.md` (версия 2, зафиксирован до запуска). Журнал: `research/experiments.csv`.
Все числа — из `reports/year/*.csv`, воспроизводятся командой `python3 scripts/run_intraday_research.py`.

## 1. Главное

1. **R-Breaker 2.1 по спецификации — отрицательное ожидание.** База (0,35 / 0,07 / 0,25): −0,30R на сделку на dev
   (975 сделок), −0,14R на holdout (534 сделки), Sharpe −10,6 / −5,7. Все 27 конфигураций сетки чувствительности
   отрицательны (от −0,33R до −0,26R). Валового преимущества нет (−0,015R при нулевых издержках): стратегию
   убивают издержки ≈ 0,23R на сделку при стопе 1–1,5 ATR 10-минутных свечей. Прогноз H001 (0,2–0,4R) подтвердился.
2. **Внутридневные семейства на 5-минутках (ORB, Дончиан, EMA, VWAP, z-score, RSI(2), сжатие, объём) — все
   отрицательны** и на фьючерсах (−0,20…−0,30R), и на акциях (−0,31…−0,50R), на уровне случайного контроля
   (−0,23R / −0,34R). Ни одного положительного тестового месяца в walk-forward.
3. **Единственное, что прошло заранее заданные правила — дневной тренд на фьючерсах** (EMA-cross, Дончиан,
   моментум): положительны на dev, в walk-forward, при STRESS_1 и на holdout (EMA-cross: +0,14R dev → +0,26R
   holdout, 51 сделка). **Но множественное тестирование их не подтверждает** (SPA p = 0,61, White RC p = 0,85,
   DSR = 0,03, BH-FDR: 0 открытий, PBO = 0,39), а случайный контроль в том же walk-forward дал Sharpe 1,04 —
   уровень шума при 5 тестовых месяцах. Статус: **гипотеза-кандидат для SHADOW, не доказанное преимущество.**
4. Цель 10% в месяц на этих данных не обоснована ничем: ни одна стратегия не имеет статистически значимого
   преимущества; размер позиции под такую цель не рассчитывался (правило плана §6: только после отбора).

## 2. Данные

* Источник — только T-Invest API (песочница, `MarketDataService/GetCandles`, биржевые свечи), 2025-09-25 → 2026-09-25.
  Локальная база `data/db/market.duckdb`, переносимый снимок `data/db/snapshot` (Parquet, 78 МБ, описание — `data/db/README.md`).
* Фьючерсы (9 базовых активов, 66 серий): MX, RN, CR, GD (основной набор спецификации R-Breaker), Si, RI, SR, GZ, BR.
  Поток активной серии: перекладка за 2 дня до экспирации или по объёму 2 дня подряд (A-08).
* Акции TQBR (12): SBER, GAZP, LKOH, ROSN, GMKN, NVTK, TATN, MGNT, PLZL, VTBR, ALRS, AFLT (survivorship bias).
* Качество: 0 нарушений OHLC; по 170–172 торговых дня dev на инструмент (`reports/year/*_data_quality.md`).
* Структурный разрыв: переход FORTS на ЕТС 23.03.2026 учтён в разметке торгового дня (тест
  `test_evening_session_trading_day_changes_with_ets`).

## 3. Методика

* Dev 2025-09-25 … 2026-05-31; FINAL HOLDOUT 2026-06-01 … 2026-09-25 (один прогон); walk-forward — расширяющееся
  окно, тестовые месяцы 2026-01 … 2026-05, выбор внутри семьи по сглаженному по соседям Sharpe.
* Исполнение: решение на закрытии свечи, исполнение на следующей; худший внутрисвечный путь; стоп-заявки +1 шаг.
  Издержки NORMAL: фьючерсы 0,025% + спред 1 шаг + проскальзывание 1 шаг; акции 0,04% + 2/2/2 б.п. (A-14).
* Риск 0,5% на сделку (разворот R-Breaker — 0,35%, §39), без сложного процента; результаты в R.
* Правила отбора (все сразу): WF OOS Sharpe > 0,3; ≥ 60% положительных тестовых месяцев; медиана Sharpe соседей > 0;
  ожидание dev > 0; затем STRESS_1 > 0.

## 8. Размер позиции и цель 10% в месяц

Не рассчитывались: по плану — только для кандидатов, прошедших статистические проверки; таких нет.
Даже по holdout-оценке EMA-cross (+0,26R, ≈ 13 сделок в месяц на 9 инструментах, риск 0,5%) доходность ≈ 1,7% в месяц
без плеча; 10% потребовали бы риска ≈ 3% на сделку — при неподтверждённом преимуществе это путь к разорению.

## 9. Ограничения

* Один год, 5 тестовых месяцев, 4 месяца holdout: малая мощность; холдаут пришёлся на трендовый период.
* Свечная модель (уровень A): без стакана спред и проскальзывание — допущения (A-05); фильтр спреда R-Breaker (§46) не применён.
* Стоимость шага — текущая из T-Invest (A-10), ГО — модельное (A-07); результаты в R от этого не зависят.
* Акции: ошибка выжившего, дивидендные гэпы не скорректированы (затрагивает только дневной свинг).
