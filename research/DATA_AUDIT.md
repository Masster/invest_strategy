# DATA AUDIT — снимок T-Invest (v2, глубокий поиск)

Дата аудита: 2026-09-25. Скрипт: `scripts/deep/a00_audit.py` (только чтение; DuckDB in-memory над Parquet).
Таблицы: `research/audit/*.csv`, факты — `research/audit/audit_facts.json`.
Контрольные суммы снимка на старте — `research/audit/snapshot_sha256_start.txt` (173 файла), сверка в конце — §9.

## 1. Хранилище и схема

| Объект | Формат | Схема |
|---|---|---|
| `data/db/snapshot/instruments.parquet` | Parquet zstd | ticker, kind (future/equity), base, uid, figi, class_code, lot, tick, tick_value, expiration, meta (JSON: last_trade, first_trade, basic_asset_size, initial_margin_buy/sell) |
| `data/db/snapshot/candles/1m/<TICKER>.parquet` (66 файлов) | Parquet zstd | ticker, interval, ts (TIMESTAMPTZ, UTC, начало свечи), open, high, low, close, volume (DOUBLE, лоты) |
| `data/db/snapshot/candles/1d/<TICKER>.parquet` (105) | Parquet zstd | то же, дневные свечи API (календарные сутки UTC, включая выходные) |
| `data/db/snapshot/fetch_log.parquet` | Parquet zstd | ticker, interval, day, n_rows, source, fetched_at (10 597 запрошенных суток 1m, 796 пустых — праздники/выходные/до начала торгов серии) |
| `data/db/market.duckdb` | DuckDB | рабочая копия (не в git); в этом исследовании не используется — данные читаются прямо из Parquet |

СУБД: DuckDB 1.x + Parquet (PyArrow). Временная зона хранения — UTC; биржевое время — МСК (UTC+3, без летнего времени).

## 2. Инструменты и история

* **Фьючерсы FORTS (SPBFUT), 9 базовых активов, 66 серий с минутками** (105 записей в instruments, включая
  дальние серии без свечей): Si (USD/RUB), CR (CNY/RUB), RI (индекс РТС), MX (индекс МосБиржи), BR (Brent),
  GD (золото), SR (Сбербанк), GZ (Газпром), RN (Роснефть).
* **Акции TQBR, 12**: SBER, GAZP, LKOH, ROSN, GMKN, NVTK, TATN, MGNT, PLZL, VTBR, ALRS, AFLT.
* Период: **2025-09-25 03:59 UTC → 2026-09-25 15:13 UTC**. Последний день неполный (выгрузка в 18:13 МСК) —
  в нормализованном слое исключён; рабочий период **2025-09-25 … 2026-09-24**: 253–256 торговых дней по фьючерсам,
  260 по акциям (акции торгуются и в дни российских праздников 23.02, 01.05, 12.06, когда нет Si/CR).
* Таймфрейм источника — **1 минута** (биржевые свечи `CANDLE_SOURCE_EXCHANGE`, только завершённые) и дневные
  свечи API. Все таймфреймы 2m…60m и дневные строятся агрегацией минуток (`moexlab.deep.data.resample`).
* Историческая глубина: **ровно 1 год**. Это главный ограничитель статистической мощности всего исследования.

## 3. Что есть и чего НЕТ

| Поле | Есть? | Комментарий |
|---|---|---|
| OHLC | да | минутные и дневные |
| Объём | да | в лотах (акции: лот 1 или 10; фьючерсы: контракты) |
| Сделки (tape) | **нет** | T-Invest отдаёт обезличенные сделки только за последний час |
| Bid / Ask / спред | **нет** | исполнение моделируется от OHLC с допущением о спреде (§7) |
| Стакан | **нет** | **Order-flow по стакану (imbalance, глубина, агрессивные сделки) невозможен.** Используются только прокси: направление и форма свечи, знаковый объём (volume × sign(close−open)), относительный объём |
| Открытый интерес | **нет** | |
| Расчётная цена / клиринг | **нет** | переоценка по close свечей |
| ГО | только **текущее** (initial_margin_buy/sell в meta, 93 серии) | историческое ГО неизвестно — используется текущее ГО в % от номинала как постоянное (Si 14,0%, CR 6,9%, RI 18,9%, MX 11,8%, BR 8,2%, GD 5,7%, SR 17,6%, GZ 21,3%, RN 20,3%) |
| Стоимость шага | только **текущая**; у 27 истёкших серий NaN | для RI/BR/GD (долларовые) стоимость шага меняется с курсом; для доходности в % от номинала не нужна, для размера позиции берётся текущая (допущение) |
| Дивиденды / корпоративные действия | **нет** | цены акций не скорректированы на дивиденды: см. §6 |

## 4. Целостность (`coverage_1m_raw.csv`, `normalized_summary.csv`)

* Дубликаты (ticker, ts): **0**. Нарушения OHLC (high < max(open,close), low > min(open,close), high < low): **0**.
  Неположительные цены: **0**. Нулевой объём: **0**. Метки не на границе минуты: **0**.
* Пропуски минут: минутка есть только при наличии сделок. Заполненность основной сессии (10:00–19:00, 540 минут),
  медиана по дням: 97–100% у всех, кроме **RN — 67%** (52 дня заполнены меньше чем наполовину; медианный объём
  9 контрактов/мин) → RN — неликвидный, для него спред в модели издержек увеличен (§7).
* Плоские минутки (high = low): от 0,6 тыс. (SiZ5) до 73 тыс. (MGNT) — норма для неликвидных минут.
* Календарь (`calendar_missing_days.csv`): у всех фьючерсов нет 04.11.2025, 31.12.2025, 02.01.2026, 07.01.2026
  (праздники FORTS); у Si/CR нет 23.02, 01.05, 12.06.2026 (валютный рынок закрыт).
* Дневные свечи API vs агрегат минуток (акции): объём совпадает (медианное отклонение 0), **close расходится
  в ~37% дней** (дневная свеча API, видимо, берёт цену закрытия основной сессии/аукциона, а не последнюю
  минутку вечерней сессии). Решение: дневные бары во всём исследовании строятся из минуток; дневные свечи API
  не используются.

## 5. Временные метки и сессии

* ts — начало минуты в UTC. Правила сессий применяются по МСК.
* Фьючерсы: до 13.07.2026 торги 09:00–23:50 МСК (утро 09:00–10:00 + единичные свечи аукциона 08:5x),
  **с 14.07.2026 — с 07:00** (расширенное утро; совпадает с сообщением MOEX, research/sources.md §6).
  Клиринги 14:00–14:05 и 18:45–19:05 видны как провалы в числе свечей.
* Переход FORTS на ЕТС 23.03.2026 меняет принадлежность вечерней сессии к торговому дню для клиринга; в этом
  исследовании торговый день = **календарная дата МСК** (вечерняя сессия относится к своему календарному дню),
  что одинаково до и после ЕТС и не использует будущих данных.
* Акции: утренняя сессия с 06:50/07:00, основная 10:00–18:40 (+аукцион закрытия), вечерняя 19:05–23:50.
  **Торги выходного дня**: у акций ≈ 50–63 тыс. минуток по субботам и воскресеньям (объём 5–10% будничного),
  у фьючерсов — ≈ 2,7–4,7 тыс. Также у акций есть **ночные свечи 02:00–06:00 МСК** (в основном в выходные,
  объём ничтожный). В нормализованном слое **свечи выходных и 00:00–06:49 МСК исключены**: стратегии в них не
  торгуют, позиция через выходные переоценивается по первой свече понедельника (гэп учитывается).
* Минутные выбросы (|ret| > 25 робастных σ, `outliers_1m.csv`): 42 из них в **13:30 МСК** — это объявления
  ключевой ставки ЦБ; остальные — открытие утренней сессии (07:00/09:00) и новости. Реальные движения,
  а не ошибки — **не удаляются**.
* Овернайт-гэпы > 3% (`overnight_gaps_gt3pct.csv`): BR (март–апрель 2026, скачок нефти 70 → 114), акции.

## 6. Смена контрактов и корпоративные действия

* Фьючерсы: поток активной серии (`data/normalized/<BASE>_1m.json` — журнал перекладок). Выбор серии на день D —
  по объёмам завершённых дней < D; обязательная перекладка за 2 торговых дня до последнего дня торгов.
  Перекладок за год: по 4 у квартальных, 12 у BR (месячные). Коэффициенты перекладки Si 0,973 / 0,997 / 0,977 /
  0,986 — **контанго ≈ 1–2,7% за квартал** (разница ставок RUB/USD); это реальный источник доходности/убытка
  (carry), который виден только на реальных ценах серий, а не на склейке.
* Исполнение — только по реальным ценам активной серии; сигнальные цены — мультипликативная форвард-корректировка
  (каузальна). На последней свече серии движок закрывает позицию (перекладка оплачивается как новый круг издержек).
* **Акции: дивидендные гэпы не скорректированы** (например SBER −10,3% 20.07.2026, VTBR −12,4% 20.07.2026,
  AFLT −15,6% 17.07.2026, LKOH −6,1% 12.01.2026). Длинная позиция через отсечку в реальности получает дивиденд,
  короткая — платит компенсацию. Поэтому: **для акций исследуются только внутридневные стратегии (без переноса
  через ночь)**; многодневные стратегии — на фьючерсах (у фьючерсов на акции SR/GZ/RN дивиденд заложен в цену
  контракта, гэпа нет).
* Ошибка выжившего: 12 акций — голубые фишки, выбранные сегодня; все торговались весь год (делистинга нет),
  но состав выбран с «знанием настоящего». Выбор инструментов внутри стратегий делается только по прошлому.

## 7. Модель исполнения и издержек (следствие аудита)

Bid/ask нет ⇒ консервативная модель уровня OHLC:
* решение на закрытии свечи; рыночный вход/выход — по open следующей свечи ± (½ спреда + проскальзывание);
* стоп — по уровню стопа, а при гэпе через уровень — по open (хуже), + 1 доп. шаг проскальзывания;
* тейк-профит/лимит — только если цена прошла уровень насквозь (high > уровня для продажи, low < уровня для
  покупки), по цене уровня, без спреда; если на одной свече достижимы и стоп, и тейк — считается стоп;
* high/low никогда не используются как цена исполнения рыночной заявки;
* комиссия Т-Инвестиций (research/sources.md §4): Трейдер — фьючерсы 0,04%, акции 0,05% за сторону (база);
  Премиум — 0,025% / 0,04% (вариант); биржевой сбор включён в брокерскую комиссию;
* спред по умолчанию 1 шаг (RN — 3 шага, MGNT/ALRS/AFLT — 2), проскальзывание 1 шаг на сторону;
  стресс: проскальзывание ×0, ×1, ×2, ×3, ×5, комиссия ×1,5.

## 8. Ограничения, которые нельзя снять этими данными

1. 1 год истории ⇒ 12 месяцев; walk-forward с шагом месяц даёт ≤ 6 честных тестовых месяцев до holdout.
2. Нет стакана/сделок ⇒ нет настоящего order flow, спред и проскальзывание — допущения.
3. ГО и стоимость шага — текущие, а не исторические.
4. Нет дивидендов ⇒ многодневные стратегии на акциях не исследуются.
5. FINAL HOLDOUT 2026-07-01 … 2026-09-24: **эти месяцы уже просматривались в анализе v1** (там holdout был
   2026-06-01 … 2026-09-25, известно, что дневной тренд на фьючерсах в нём был прибыльным). Для v2 holdout
   не используется ни при выборе гипотез, ни параметров, ни инструментов; но полностью «слепым» он не является.
