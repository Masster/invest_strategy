# Замороженные кандидаты (до вскрытия FINAL HOLDOUT)

Дата фиксации: 2026-09-25, до любого расчёта результатов на 2026-07-01 … 2026-09-24.
Определения — `src/moexlab/deep/candidates.py` (FROZEN), библиотека — `src/moexlab/deep/panel_lib.py`.
Все — дневные портфели: решение на закрытии дня, исполнение на открытии следующего; издержки Трейдер
(фьючерсы 0,04%, акции 0,05%) + ½ спреда + 1 шаг проскальзывания; перенос шорта акций 0,068%/день;
размер — таргет волатильности 10% годовых по прошлым 60 дням.

| ID | Что | Почему выбран (только по данным ≤ 2026-06-30) |
|---|---|---|
| C1_TREND_FUT_ENS | ансамбль всех трендовых конфигураций (TSMOM/EMA/пробой) на 9 фьючерсах, без отбора параметров | единственное семейство с устойчивым плюсом вне выборки в v1 и в карте предсказуемости v2 (6/6 тестовых месяцев у ансамблей T_ADX, T_EMA_X) |
| C2_TREND_ALL_ENS | то же на всех 21 инструменте | проверка расширения на акции |
| C3_XSMOM_EQ_ENS | ансамбль кросс-секционного моментума акций (рыночно-нейтральный) | другой источник, низкая корреляция с C1 |
| C4_CARRY_FX | шорт Si и CR | структурная премия (контанго ≈ 1–2,7% за квартал) |
| C5_TREND_FUT_LONGONLY | только лонг-сторона тренда | контроль: зависимость от медвежьего режима разработки |
| C6_WF_PANEL_SHARPE_K10_SMOOTH | процедура walk-forward: 10 стратегий библиотеки по Sharpe, сглаженному по группе параметров | устойчивые области параметров (§47) |
| C7_WF_PANEL_SORTINO_K1 | процедура: 1 лучшая по Sortino | лучшая процедура WF (контроль смещения отбора) |
| C8_WF_PANEL_FLOOR_K5 | процедура: 5 стратегий по максимуму худшего месяца | floor-ориентированный поиск (§39) |
| C9_META_RP | риск-паритет C1 + C3 + C4, веса по прошлой волатильности | мета-стратегия (§64–65) |

Отвергнуто до holdout (не проверяется на нём): внутридневные семейства 1m–60m (1,08 млн конфигураций),
lead-lag и пары (43 тыс.), акции с переносом (191 тыс.), ночной дрейф, ML (LightGBM дневной и часовой) —
отрицательны после издержек в walk-forward. Holdout-месяцы частично видел анализ v1 (DATA_AUDIT §8.5).
