# План исследования (зафиксирован до запуска на реальных данных)

Дата фиксации: 2026-09-25. Любое изменение правил ниже — новая запись в `research/experiments.csv`.

## 0. Ограничения окружения (известны заранее)

| Ресурс | Статус | Следствие |
|---|---|---|
| `iss.moex.com`, `invest-public-api.tbank.ru`, `sandbox-invest-public-api.tbank.ru` | закрыты сетевой политикой окружения (HTTP 403 на CONNECT) | прямой загрузки данных нет |
| `TBANK_TOKEN` | не задан | API Т-Инвестиций / MCP недоступны |
| Firecrawl (веб-скрейпер) | доступен, JSON с ISS читается | только **дневные** свечи реальных серий фьючерсов и акций (минутные — десятки млн токенов) |

Следствие: исследование в этой сессии — **дневной горизонт** (удержание от 1 дня). Внутридневные гипотезы
(R-Breaker 2.1 в исходном виде, VWAP, ORB, микроструктура) реализованы в коде и проверены на синтетике,
но на реальных данных **не оцениваются** до открытия доступа (раздел 7).

## 1. Данные

* Фьючерсы: Si, RI, MX, GD, SR, GZ, CR, BR — реальные серии (квартальные; BR — месячные), 2020-01 → 2026-09.
  Поток активной серии: обязательная перекладка за 2 торговых дня до экспирации; досрочная — объём следующей
  серии выше 2 дня подряд (спред на истории недоступен — отклонение A-08).
* Сигнальные цены — форвард-корректировка перекладок (каузальна); цены исполнения — реальные цены серии.
* Акции (отдельный класс EQUITY_STRATEGIES): SBER, GAZP, LKOH, ROSN, GMKN, NVTK, TATN, MGNT, PLZL, VTBR, ALRS, AFLT.
  Выбор по текущей ликвидности => **survivorship bias** (отмечается в отчёте). Дивидендные гэпы не скорректированы.
* Качество: `DATA_QUALITY = LLM_TRANSCRIBED` — проверки OHLC-согласованности, монотонности дат, скачков >25%,
  выборочная повторная загрузка.

## 2. Разбиение по времени

* **Разработка (dev):** 2020-01-01 … 2025-09-30.
* **FINAL HOLDOUT:** 2025-10-01 … 2026-09-25. Код этапа разработки получает данные, обрезанные по 2025-09-30.
  Holdout прогоняется один раз, только для отобранных кандидатов, после фиксации их параметров.
  Оговорка: я видел общую историю рынка 2020–2026 в обучающих данных модели; поэтому holdout — независим от
  подбора параметров, но не является «слепым» в строгом смысле.
* **Walk-forward (расширяющееся окно):** обучение 2020…(Y−1), проверка год Y, Y ∈ {2022, 2023, 2024, 2025*}
  (*2025 — до 30.09). Выбор конфигурации внутри семьи — по сглаженному по соседям Sharpe (плато, а не пик).

## 3. Гипотезы (сетка `daily-v1`, 77 конфигураций, 11 семейств)

Тренд (Donchian, EMA-cross, SuperTrend±ADX), моментум (TSMOM 20/60/120/250/мульти), возврат к среднему
(z-score, RSI(2)±фильтр тренда), волатильность (сжатие Боллинджера, расширение диапазона ± NR7), объём
(пробой с относительным объёмом), BASELINE_01_RBREAKER_DAILY (только пробойная часть, аппроксимация),
CONTROL_RANDOM (обязан быть отрицательным после издержек).

## 4. Модель исполнения и издержек (NORMAL)

* Комиссия 0,025% оборота на сторону (Премиум ≤ 12 млн ₽/день; тариф Private не подтверждён — чувствительность
  0,04% и 0,06%). Биржевой сбор включён в комиссию брокера (research/sources.md §4).
* Спред 1 шаг, проскальзывание 1 шаг, стоп-заявки +1 шаг (проскок уровня). STRESS_1: спред ×1,5, проскальзывание ×2;
  STRESS_2: ×2 / ×3. Задержка 0…2000 мс (на дневном горизонте пренебрежимо мала — показывается формально).
* Внутри свечи всегда худший допустимый порядок цен. Стоп-заявки разных направлений в одной свече —
  берётся худший вариант (не пропуск: пропуск = заглядывание в будущее).
* Размер позиции для оценки сигнала: 0,5% начального капитала на сделку, без сложного процента, дробные контракты.

## 5. Правила отбора кандидатов (зафиксированы заранее)

Семейство проходит, если одновременно:
1. walk-forward OOS Sharpe (склейка тестовых лет) > 0,3;
2. доля тестовых лет с положительной доходностью ≥ 60%;
3. медиана in-sample Sharpe соседей выбранной конфигурации > 0 (плато);
4. ожидание в R выбранной конфигурации на dev > 0 после издержек NORMAL.

Далее для прошедших: STRESS_1 > 0 (обязательно), STRESS_2 — не разрушает; поверхность стоп × трейлинг;
10 вариантов выхода; удаление лучших сделок/дней; Монте-Карло 10 000; holdout один раз.

Множественное тестирование: BH-FDR 10% по бутстреп-p всех конфигураций; Hansen SPA и White RC по всей сетке и
по семьям; PBO (CSCV, 12 блоков); DSR с эффективным числом испытаний (participation ratio).
Если ни одно семейство не проходит — это и есть результат («устойчивого преимущества не найдено»);
тогда 3 лучших по WF показываются с меткой BEST_OF_FAILED.

## 6. Размер позиции / цель 10% в месяц

Только после отбора: масштабирование риска, рост log-капитала, доля Келли, требуемый риск и плечо для
5 / 7,5 / 10 / 15% в месяц, исторические и бутстреп-просадки, P(DD > 10/20/30/50%).

## 7. Что требуется для полной программы (внутридневной горизонт)

1. Открыть в Network access окружения: `iss.moex.com`, `invest-public-api.tbank.ru`,
   `sandbox-invest-public-api.tbank.ru` (+ `www.moex.com` для документов).
2. Секрет `TBANK_TOKEN` (только чтение) в переменных окружения.
3. Запуск: `python3 scripts/fetch_tinvest_history.py` (минутные архивы history-data) →
   `python3 scripts/run_intraday_research.py` (R-Breaker 2.1 по спецификации, VWAP/ORB/объём).

# Версия 2 плана (зафиксирована 2026-09-25 до запуска на реальных данных T-Invest)

Причина пересмотра (решение владельца исследования): все данные берутся из T-Invest API, горизонт истории —
**один год** (2025-09-25 → 2026-09-25), глубже не загружать. Сеть к T-Invest открыта (установлены корневые
сертификаты НУЦ Минцифры), токен — песочница (только чтение рыночных данных; архив history-data недоступен,
используется MarketDataService/GetCandles, свечи CANDLE_SOURCE_EXCHANGE). Правила версии 1 для многолетней
дневной истории к этому набору не применимы и заменяются правилами ниже. Запись в research/experiments.csv.

## v2.1 Данные
* База `data/db/market.duckdb` (снимок Parquet в `data/db/snapshot` хранится в git): инструменты (шаг цены,
  стоимость шага, лот, экспирация, ГО — из T-Invest), дневные свечи API, минутные свечи.
* Фьючерсы Si, RI, MX, RN, GD, SR, GZ, CR, BR: минутки серий, имевших ≥ 10% дневного объёма базового актива
  хотя бы в один день, плюс 40 календарных дней истории до этого (R-Breaker §7–8: 20 завершённых дней серии).
* Акции TQBR: SBER, GAZP, LKOH, ROSN, GMKN, NVTK, TATN, MGNT, PLZL, VTBR, ALRS, AFLT (survivorship bias;
  дивидендные гэпы не корректируются — во внутридневной торговле позиции на ночь не переносятся).
* Торговый день: до ЕТС (до вечера 20.03.2026) вечерняя сессия FORTS относится к следующему дню, с ЕТС — к текущему.
  Дневные свечи для дневных стратегий строятся из минуток по торговым дням (не календарные свечи API).

## v2.2 Разбиение по времени
* Первые 20 торговых дней каждой серии — прогрев (сделок нет по правилу минимальной истории).
* **Разработка (dev):** торговые дни 2025-09-25 … 2026-05-31.
* **FINAL HOLDOUT:** 2026-06-01 … 2026-09-25 (≈ 4 месяца). Прогоняется один раз для отобранных кандидатов.
* **Walk-forward (расширяющееся окно):** обучение с начала данных до конца месяца M−1, проверка месяц M,
  M ∈ {2026-01, 2026-02, 2026-03, 2026-04, 2026-05}. Выбор конфигурации внутри семьи — сглаженный по соседям
  Sharpe на обучении (минимум 20 активных дней).
* Структурный разрыв внутри выборки: переход FORTS на ЕТС 23.03.2026 — результаты показываются до/после.

## v2.3 Гипотезы (сетки фиксируются в `src/moexlab/research/grid_intraday.py`, версия `intraday-v1`)
1. **H-RB (R-Breaker 2.1 по спецификации)** на минутных свечах, фьючерсы. Основной набор спецификации:
   MX, RN, CR, GD; дополнительно Si, RI, SR, GZ, BR (отдельно). Базовые коэффициенты — из спецификации
   (0,35 / 0,07 / 0,25); чувствительность 3×3×3: setup_k {0,25; 0,35; 0,45} × reversal_k {0,05; 0,07; 0,10} ×
   breakout_k {0,15; 0,25; 0,35} — только для проверки плато, не для выбора лучшего.
2. **H-ID (внутридневные семейства)** на 5-минутных свечах, позиция закрывается до конца основной сессии:
   пробой диапазона открытия (ORB), Дончиан, пересечение EMA, возврат к VWAP, z-score, RSI(2), сжатие Боллинджера,
   пробой с объёмом, контроль CONTROL_RANDOM. Фьючерсы и акции — отдельные вселенные.
3. **H-DAY (дневной свинг, низкая мощность)** на дневных свечах из минуток, окна ≤ 40 дней. Сделок на году мало —
   результат информативен только при очень сильном эффекте.

## v2.4 Издержки (NORMAL), отбор, статистика
* Фьючерсы: комиссия 0,025% на сторону (A-06), спред 1 шаг, проскальзывание 1 шаг, стоп +1 шаг; реальные шаг
  и стоимость шага из T-Invest. Акции: комиссия 0,04%, относительная модель A-14 (спред 2 б.п., проскальзывание 2 б.п.,
  стоп +2 б.п.). STRESS_1 / STRESS_2 как в версии 1.
* Правила отбора семейства (все одновременно): WF OOS Sharpe (склейка 5 тестовых месяцев) > 0,3; доля
  положительных тестовых месяцев ≥ 60%; медиана Sharpe соседей на обучении > 0; ожидание в R на dev > 0 (NORMAL).
  Далее: STRESS_1 > 0 обязательно; holdout — один раз.
* Множественное тестирование по всем конфигурациям каждой вселенной: бутстреп-p + BH-FDR 10%, White RC,
  Hansen SPA, PBO (CSCV, 8 блоков), DSR с эффективным числом испытаний.
* Если ни одно семейство не проходит — это результат; показываются 3 лучших по WF с меткой BEST_OF_FAILED.
* База R-Breaker 2.1 с коэффициентами спецификации заявлена заранее (не выбирается по данным), поэтому
  прогоняется на holdout независимо от прохождения правил отбора; её раздельная статистика (§76–82: инструмент,
  направление, тип сигнала, до/после ЕТС, издержки ZERO/NORMAL/STRESS, удаление лучших сделок) считается за весь год.
