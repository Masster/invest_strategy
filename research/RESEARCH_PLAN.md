## 2. Разбиение по времени

* **Разработка (dev):** 2020-01-01 … 2025-09-30.
* **FINAL HOLDOUT:** 2025-10-01 … 2026-09-25. Код этапа разработки получает данные, обрезанные по 2025-09-30.
  Holdout прогоняется один раз, только для отобранных кандидатов, после фиксации их параметров.
  Оговорка: я видел общую историю рынка 2020–2026 в обучающих данных модели; поэтому holdout — независим от
  подбора параметров, но не является «слепым» в строгом смысле.
* **Walk-forward (расширяющееся окно):** обучение 2020…(Y−1), проверка год Y, Y ∈ {2022, 2023, 2024, 2025*}
  (*2025 — до 30.09). Выбор конфигурации внутри семьи — по сглаженному по соседям Sharpe (плато, а не пик).

## 3. Гипотезы (сетка `daily-v1`, 77 конфигураций, 11 семейств)

Тренд (Donchian, EMA-cross, SuperTrend±ADX), моментум (TSMOM 20/60/120/250/мульти), возврат к среднему
(z-score, RSI(2)±фильтр тренда), волатильность (сжатие Боллинджера, расширение диапазона ± NR7), объём
(пробой с относительным объёмом), BASELINE_01_RBREAKER_DAILY (только пробойная часть, аппроксимация),
CONTROL_RANDOM (обязан быть отрицательным после издержек).

## 4. Модель исполнения и издержек (NORMAL)

* Комиссия 0,025% оборота на сторону (Премиум ≤ 12 млн ₽/день; тариф Private не подтверждён — чувствительность
  0,04% и 0,06%). Биржевой сбор включён в комиссию брокера (research/sources.md §4).
* Спред 1 шаг, проскальзывание 1 шаг, стоп-заявки +1 шаг (проскок уровня). STRESS_1: спред ×1,5, проскальзывание ×2;
  STRESS_2: ×2 / ×3. Задержка 0…2000 мс (на дневном горизонте пренебрежимо мала — показывается формально).
* Внутри свечи всегда худший допустимый порядок цен. Стоп-заявки разных направлений в одной свече —
  берётся худший вариант (не пропуск: пропуск = заглядывание в будущее).
* Размер позиции для оценки сигнала: 0,5% начального капитала на сделку, без сложного процента, дробные контракты.

## 5. Правила отбора кандидатов (зафиксированы заранее)

Семейство проходит, если одновременно:
1. walk-forward OOS Sharpe (склейка тестовых лет) > 0,3;
2. доля тестовых лет с положительной доходностью ≥ 60%;
3. медиана in-sample Sharpe соседей выбранной конфигурации > 0 (плато);
4. ожидание в R выбранной конфигурации на dev > 0 после издержек NORMAL.

Далее для прошедших: STRESS_1 > 0 (обязательно), STRESS_2 — не разрушает; поверхность стоп × трейлинг;
10 вариантов выхода; удаление лучших сделок/дней; Монте-Карло 10 000; holdout один раз.

Множественное тестирование: BH-FDR 10% по бутстреп-p всех конфигураций; Hansen SPA и White RC по всей сетке и
по семьям; PBO (CSCV, 12 блоков); DSR с эффективным числом испытаний (participation ratio).
Если ни одно семейство не проходит — это и есть результат («устойчивого преимущества не найдено»);
тогда 3 лучших по WF показываются с меткой BEST_OF_FAILED.

## 6. Размер позиции / цель 10% в месяц
