# План исследования (версия 2, зафиксирована 2026-09-25 до запуска на реальных данных)

Решение владельца исследования: **единственный источник данных — T-Invest API** (брокер, через которого
планируется торговля), горизонт истории — **один год** (2025-09-25 → 2026-09-25), глубже не загружать. Сеть к T-Invest открыта (установлены корневые
сертификаты НУЦ Минцифры), токен — песочница (только чтение рыночных данных; архив history-data недоступен,
используется MarketDataService/GetCandles, свечи CANDLE_SOURCE_EXCHANGE). Любое изменение правил —
новая запись в research/experiments.csv.

## v2.1 Данные
* База `data/db/market.duckdb` (снимок Parquet в `data/db/snapshot` хранится в git): инструменты (шаг цены,
  стоимость шага, лот, экспирация, ГО — из T-Invest), дневные свечи API, минутные свечи.
* Фьючерсы Si, RI, MX, RN, GD, SR, GZ, CR, BR: минутки серий, имевших ≥ 10% дневного объёма базового актива
  хотя бы в один день, плюс 40 календарных дней истории до этого (R-Breaker §7–8: 20 завершённых дней серии).
* Акции TQBR: SBER, GAZP, LKOH, ROSN, GMKN, NVTK, TATN, MGNT, PLZL, VTBR, ALRS, AFLT (survivorship bias;
  дивидендные гэпы не корректируются — во внутридневной торговле позиции на ночь не переносятся).
* Торговый день: до ЕТС (до вечера 20.03.2026) вечерняя сессия FORTS относится к следующему дню, с ЕТС — к текущему.
  Дневные свечи для дневных стратегий строятся из минуток по торговым дням (не календарные свечи API).

## v2.2 Разбиение по времени
* Первые 20 торговых дней каждой серии — прогрев (сделок нет по правилу минимальной истории).
* **Разработка (dev):** торговые дни 2025-09-25 … 2026-05-31.
* **FINAL HOLDOUT:** 2026-06-01 … 2026-09-25 (≈ 4 месяца). Прогоняется один раз для отобранных кандидатов.
* **Walk-forward (расширяющееся окно):** обучение с начала данных до конца месяца M−1, проверка месяц M,
  M ∈ {2026-01, 2026-02, 2026-03, 2026-04, 2026-05}. Выбор конфигурации внутри семьи — сглаженный по соседям
  Sharpe на обучении (минимум 20 активных дней).
* Структурный разрыв внутри выборки: переход FORTS на ЕТС 23.03.2026 — результаты показываются до/после.

## v2.3 Гипотезы (сетки фиксируются в `src/moexlab/research/grid_intraday.py`, версия `intraday-v1`)
1. **H-RB (R-Breaker 2.1 по спецификации)** на минутных свечах, фьючерсы. Основной набор спецификации:
   MX, RN, CR, GD; дополнительно Si, RI, SR, GZ, BR (отдельно). Базовые коэффициенты — из спецификации
   (0,35 / 0,07 / 0,25); чувствительность 3×3×3: setup_k {0,25; 0,35; 0,45} × reversal_k {0,05; 0,07; 0,10} ×
   breakout_k {0,15; 0,25; 0,35} — только для проверки плато, не для выбора лучшего.
2. **H-ID (внутридневные семейства)** на 5-минутных свечах, позиция закрывается до конца основной сессии:
   пробой диапазона открытия (ORB), Дончиан, пересечение EMA, возврат к VWAP, z-score, RSI(2), сжатие Боллинджера,
   пробой с объёмом, контроль CONTROL_RANDOM. Фьючерсы и акции — отдельные вселенные.
3. **H-DAY (дневной свинг, низкая мощность)** на дневных свечах из минуток, окна ≤ 40 дней. Сделок на году мало —
   результат информативен только при очень сильном эффекте.

## v2.4 Издержки (NORMAL), отбор, статистика
* Фьючерсы: комиссия 0,025% на сторону (A-06), спред 1 шаг, проскальзывание 1 шаг, стоп +1 шаг; реальные шаг
  и стоимость шага из T-Invest. Акции: комиссия 0,04%, относительная модель A-14 (спред 2 б.п., проскальзывание 2 б.п.,
  стоп +2 б.п.). STRESS_1: спред ×1,5, проскальзывание ×2; STRESS_2: ×2 / ×3.
* Правила отбора семейства (все одновременно): WF OOS Sharpe (склейка 5 тестовых месяцев) > 0,3; доля
  положительных тестовых месяцев ≥ 60%; медиана Sharpe соседей на обучении > 0; ожидание в R на dev > 0 (NORMAL).
  Далее: STRESS_1 > 0 обязательно; holdout — один раз.
* Множественное тестирование по всем конфигурациям каждой вселенной: бутстреп-p + BH-FDR 10%, White RC,
  Hansen SPA, PBO (CSCV, 8 блоков), DSR с эффективным числом испытаний.
* Если ни одно семейство не проходит — это результат; показываются 3 лучших по WF с меткой BEST_OF_FAILED.
* База R-Breaker 2.1 с коэффициентами спецификации заявлена заранее (не выбирается по данным), поэтому
  прогоняется на holdout независимо от прохождения правил отбора; её раздельная статистика (§76–82: инструмент,
  направление, тип сигнала, до/после ЕТС, издержки ZERO/NORMAL/STRESS, удаление лучших сделок) считается за весь год.

# Задача 2: максимум прибыли на фьючерсах при ограниченном риске (v3, зафиксировано 2026-09-25 до расчёта)

**Стратегия A (без изменений):** DAY_FUT TF_EMA_CROSS (5/20), риск 0,5% на сделку, без сложного процента.

**Стратегия B (агрессивная):** тот же источник преимущества, но с оптимальным размером позиции.
* Сигналы — только три семейства, прошедшие правила v2 (DAY_FUT: TF_EMA_CROSS, TF_DONCHIAN, MOM_TSMOM, финальные
  конфигурации из `reports/year/DAY_FUT_selection.csv`). Нового перебора стратегий нет: holdout уже просмотрен,
  новый поиск на тех же данных был бы подгонкой.
* **Бюджет риска (выбор исследователя):** «рискованная, но высокодоходная» = вероятность просадки больше 25% за
  12 месяцев не выше 5% (бутстреп); жёсткая остановка торговли при просадке 30%; при просадке 15% риск вдвое
  меньше; дневной лимит убытка 5%, недельный 10%; суммарное ГО (реальные ставки T-Invest) ≤ 60% капитала.
  Обоснование: 25–30% — типичная максимальная просадка агрессивных трендовых фондов; после −30% для
  возврата нужно +43%, глубже — риск необратимого ущерба.
* **Цель:** максимум медианного роста капитала за 12 месяцев (сложный процент) при этих ограничениях.
  Варианты построения: (a) только EMA-cross; (b) равный риск трёх семейств; (c) веса обратно волатильности (по dev).
  Выбор — по dev.
* **Поправка на неуверенность в преимуществе:** проверки множественного тестирования его не подтвердили,
  поэтому размер считается по дневным доходностям dev со средним, **уменьшенным вдвое**; множитель риска не выше
  половины Келли (по уменьшенному среднему). Для сравнения показывается и расчёт без поправки.
* **Проверка:** событийный движок со сложным процентом, целыми контрактами, реальными шагом, стоимостью шага и ГО
  из T-Invest, активными лимитами риска; капитал 1 000 000 ₽ (чувствительность 300 000 и 3 000 000 ₽);
  NORMAL и STRESS_1; отдельно dev и holdout. Holdout здесь — **повторный просмотр**, не слепая проверка.
